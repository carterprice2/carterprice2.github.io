Vision · 2022–2023

Real-time multi-camera vision for battery cell sorting

I built a real-time computer vision system for battery cell sorting that combined 3D sensing with multi-camera classification. Volumetric measurement came from a laser-line triangulation sensor — a line laser projected onto the cell surface and read by an angled camera, from which we estimated height and used it for object detection and volume estimation. That gave us the physical geometry of each cell as it moved through the line.

For classification, we built two camera cells of six Lucid Vision Labs cameras each — one monochrome cell dedicated to OCR, shooting overhead and multiple side angles to read cell markings, and one RGB cell feeding a trained classification model. Both cells used controlled, pulsed lighting timed to a short exposure window, which let us freeze fast-moving cells without motion blur instead of relying on longer exposures.

On the compute side, image acquisition ran through C++ drivers I wrote to interface with the cameras and pull frames in over Gigabit Ethernet, feeding a rack-mounted, multi-GPU compute module dedicated to running the vision models in real time. It was a full-stack build — sensor selection and hardware integration, custom driver code, and the ML/OCR pipeline — all engineered to run inline on a live production sorting line rather than offline.
