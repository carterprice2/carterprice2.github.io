Files prefixed with `_` are ignored by the content loader, so this template never
ships. To publish a post: copy it to `src/content/writing/some-slug.mdx`, set
`draft: false`, and it appears at `/writing/some-slug/` and in the RSS feed.

The `Writing` link stays out of the homepage navigation until there is at least one
real post — an empty writing section reads worse than no writing section. Uncomment
the entry in `src/data/site.ts` when you publish the first one.

## A heading

Body copy, **bold**, `inline code`, and links all pick up the site styles.

const example = 'fenced code blocks are styled too'
